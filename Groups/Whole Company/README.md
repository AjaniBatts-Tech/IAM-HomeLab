# Whole Company

Overview

- This folder documents the entire company into one group within the IAM Home Lab.
- This group is automatically created by Microsoft 365 and includes all users in the organization.
- It serves as the default communication and collaboration group for company-wide announcements, shared resources, and global policy targeting.
