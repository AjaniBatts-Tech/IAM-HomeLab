# Dynamic Sales Group

Overview

- This folder documents the Dynamic-Sales group within the IAM Home Lab.
- The group represents users in the Sales department and is configured with dynamic membership rules that automatically add or remove users based on their attributes in Microsoft Entra ID.
- It demonstrates how identity teams use automation to accurate, up-to-date group memberships.
