# Privileged Access

Overview

- This folder documents the Privileged Access group within the IAM Home Lab.
- This group is designed to contain accounts with elevated administrative permissions.
- It demonstrates how identity teams isolate privileged roles to enforce least-privilege principles and protect critical resources.
