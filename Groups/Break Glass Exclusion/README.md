# Break Glass Exclusion

Overview

- This folder documents the Break Glass Exclusion group in the IAM Home Lab.
- The group is designed to provide emergency administrative access when normal authentication mechanisms fail.
- This is a critical safeguard in my enterprise identity management environment.
