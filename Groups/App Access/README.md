# App Access

Overview

- This folder documents the App Access group within the IAM Home Lab.
- The group is designed to manage access to enterprise applications through Microsoft Entra ID.
- It demonstrated how identity teams assign permissions to users who require access to specific apps while maintained least-privilege principles.
