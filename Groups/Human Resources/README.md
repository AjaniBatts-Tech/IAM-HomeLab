# Human Resources

Overview

- This folder documents the Human Resources (HR) group within the IAM Home Lab.
- The group represents users in the HR department and is used to manage access to HR systems, employee data, and sensitive organizational information.
- It demonstrates how identity teams structure departmental groups to enforce least-privilege access and compliance controls.
