#  Finance

Overview

- This folder documents the Finance group within the IAM Home Lab.
- The group represents users in the Finance department and is used to manage access to financial systems, reports, and sensitive data.
- It demonstrates how departmental groups can be structured to enforce least-privilege access and simplify identity governance.
