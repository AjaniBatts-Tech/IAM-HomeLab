# IAM-HomeLab
A fully documented Active Directory / Microsoft Entra ID Identity & Access Management (IAM) Home Lab.
It will demonstrate identity lifecycle automation, MFA, Conditional Access, privileged access controls, authentication methods, and enterprise-grade security architecture.

# Overview 
This repository showcases a complete IAM environment built in Microsoft Entra ID.
It includes:
- Identity Lifecycle (joiner/mover/leaver)
- Conditional Access policies
- MFA enforcement
- Authentication methods
- Password protection
- Privileged access management
- Dynamic groups
- Device‑based access controls
- Documentation of every configuration with sanitized screenshots
